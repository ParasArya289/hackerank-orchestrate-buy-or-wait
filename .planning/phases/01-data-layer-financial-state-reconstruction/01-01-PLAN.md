<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| dataset CSVs -> pandas loaders | Untrusted-shape input (blank cells, mixed types); must not silently coerce blanks to 0 |
| images.csv/media PNGs -> vision extraction | Untrusted file references; must validate the image file actually exists before use |
| messages.csv text -> future LLM layer (Phase 3) | Untrusted free text; this phase does not parse message content for facts, but must not let message_text leak into any code path that executes it |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|------------------|
| T-01-01 | Information Disclosure | code/dataio/loaders.py | accept | Local CSV files only, no network I/O, no secrets involved |
| T-01-02 | Tampering | code/dataio/vision_stub.py | mitigate | `resolve_blank_amount` asserts the image file exists via `os.path.exists` before any extraction attempt; raises rather than silently defaulting to 0 |
| T-01-03 | Repudiation | code/dataio/fx.py | mitigate | `convert_amount` raises `ValueError` naming the missing currency pair/date rather than silently applying a fabricated rate (AGENTS.md: never invent unsupported financial facts) |
| T-01-SC | Tampering | pip/package installs | accept | Task 1/2 introduce zero new third-party dependencies (pandas already implied by PROJECT.md stack decision, stdlib unittest for tests) |
</threat_model>
